# Gameplay Result Cards

Correct / incorrect result screens with an animated reveal: masked
letter-by-letter headline, card slide-up, animated background gradient.

## Setup

```bash
npm install
npm run dev
```

## Structure

- `src/App.jsx` — demo shell with Correct/Incorrect/Replay controls
- `src/ResultScreen.jsx` — the result screen itself
- `src/SwipeIcon.jsx` — swipe icon
- `codepen-css.css` / `codepen-js.jsx` — flattened single-file version for CodePen
